# トップライバーへの道 九州編・四国中国編（公開版）

男女混合アイドルグループを脱退したヒロインと2人で旅立ち、九州・沖縄で仲間を集めてS6トップライバーへ導く、昭和風ドットのスマホ向けRPGです。

- 遊び方：`index.html` を開くだけ（スマホの縦画面向け）。GitHub Pages で公開しています。
- 収録範囲：九州・沖縄17拠点＋四国・中国9拠点。本編M01～M17・C01～C09（大牟田編M17は任意）
- 記録：遊んでいるブラウザ内に自動保存されます。閲覧データを消すと記録も消えるので、設定の「バックアップを表示」で控えを取ってください。

## ご注意

配信文化を参考にした**非公式の創作ゲーム**です。人物・台詞・敵・数値・画像・音はゲーム用の創作で、実在のサービスの配信・課金・アカウント・ランキングとは連携しません。

## 更新について

この公開版は、制作者が確認したうえで手動で更新します。開発中の版とは内容が異なる場合があります。版と更新日は `VERSION.txt` とタイトル画面に表示しています。

## v6.18 デバッグ修正

- 一度解放した特設エリア・特設チャレンジの案内が、同行者変更でパーティレベルが下がると消える不具合を修正。解放記録はセーブに残し、入場条件を満たさない場合は「解放済み・準備待ち」と表示します。入場条件は維持します。
- 四国・中国編の依頼帳に表示される経験値を、実際の完了報酬と同じ計算に統一しました。
- 仲間ごとのレベルが異なる場合、装備比較などのメーター突破・ファミリー応援の威力表示に各キャラのレベルを使うよう修正しました。
- 配信待ちの街から駅や徒歩の出口で離れられる問題を修正。既に離れた街にいる旧セーブからは、配信待ちの街に戻れるようにしました。拒否された移動では運賃・旅程枠を消費しません。
- 検証：全26都市の主要メニュー・ストーリー進行・戦闘と報酬、全88エリアの敵データ、全22職の能力・MP成長、レベル／熟練度999、650通りの街配置、セーブ復元・破損データの予備読み込み、5件の不具合の再発防止をコード上で確認しました。実機ブラウザの表示・タッチ操作は今回の検証に含みません。

## v6.16 四国・中国エリア編

- 九州本編M16クリア後、地図の「四国・中国エリア編の進行・出発」、またはファミリー交流所から松山市へ出発できます。M17のクリアは不要です。
- 松山→高知→徳島→高松→岡山→鳥取→松江→山口→広島の9都市。本編C01～C09、任意依頼CS01～CS09、街の交流祭9件、通常敵27エリア（各50種）、地域ボス9体を追加しました。
- 街ごとの合同配信の物語が進むと、次の都市が解放されます。配信目標がある本編は、ボス撃破後に依頼帳から配信を行います。
- レベル・同行者・装備・名前・ジョブ熟練度・習得技・九州の進行を引き継ぎます。九州クリア済みの既存セーブでも解放されます。
