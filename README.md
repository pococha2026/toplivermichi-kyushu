# トップライバーへの道 全国ツアー編（公開版 v7.00）

アイドルグループ「おやすみセカイ」を脱退したヒロインと、その後に出会った主人公が全国を巡る、昭和風ドットのスマホ向けRPGです。グラドル出演・グラビア撮影会・Pococha配信を重ね、九州のS6到達から、東京ドーム満員の公演と全国的な成功へ進みます。

**プレイ： https://pococha2026.github.io/toplivermichi-kyushu/**

## 今回の追加

- 各地で撮影会・グラドル活動イベントを準備し、成功を活動記録へ保存。「全国・地図」またはファミリー施設の「活動予定」で確認できます。東京ドーム本番には全6地域で撮影会・出演を各1件以上成功させます。未達の地域も一覧で確認できます。
- 「全国・地図」→「日本地図」で解放済みの拠点を表示。国土地理院の白地図、照合した市区町村の緯度経度、拡大縮小・方向移動・公式地図リンクを利用できます。画像には通信が必要です。代表点は市区町村内の目印で、会場の入口を表しません。
- 「人物相関図」で主人公・ヒロイン・仲間・登場したNPCの関係を確認。主要NPC9人を追加し、新しい人物との出会い・会話・二人の約束に応じて表示が更新されます。各地の方言や口癖も会話に反映します。
- おやすみセカイの構成は詳細画面だけで説明。ヒロイン在籍時の6人として元の仲間5人が各地に登場し、今の夢を応援します。
- 新都市の地域ボス、街の事件と解決後の反応、ショップ装備、22職の全国奥義176件を追加。各編の上限に近い育成と装備・職業技を攻略の目安にしています。
- 地域特別エリアは本編と別に挑戦でき、未クリアの表示を残します。追加5地域のボス初回報酬には共演証を用意しました。

詳しい現行仕様・整合性の判断・全拠点と推奨レベルは [ゲーム制作指示書](GAME_SPEC.md) を参照してください。

## 継承する遊びと記録

- 主人公とヒロインの2人で開始し、仲間は計9人。同行最大4人、控えには戦闘経験値・熟練度を与えず、ファミリー施設で入れ替えます。
- 22職、職業別熟練度、転職時の技・熟練度・永続ボーナスの継承、共通装備の個人レベル条件、職業専用装備の熟練度条件を維持します。
- 9人の固有特性と固有必殺技、全36話の絆エピソード、恋人／かけがえのない相棒の選択を維持。どちらの関係でも二人の大成功とハッピーエンドを描きます。
- HP・MPを戦闘後も持ち越し、宿屋で回復。技はMPを消費します。ボス戦・特別チャレンジは手動のみ、通常戦闘でオートを使えます。
- 同じ公開URLと保存キーを維持します。既存の獲得経験値・名前・所持品・職業・進行・絆・戦闘中の記録は引き継ぎます。旧記録の上限超過分は削除せず、次の上限解放まで保留します。
- 自動保存は遊ぶ人それぞれのブラウザ内。閲覧データを消すと記録も消えるため、設定の「バックアップを表示」で控えを取ってください。別の端末や個人版との移行は「記録の復元」を使います。

## 交通・地理・創作

地図の県境・海岸線と地名代表点の資料は国土地理院。街のレイアウト、駅、撮影会場、催し、人物の関係は創作です。全国の駅は船・空路も含めた広域交通として扱い、運賃は20G＋ゲーム内距離（地名代表点間の直線距離km×1.25の切上げ）。現実の直通路線・運賃ではありません。

配信文化を参考にした**非公式の創作ゲーム**です。作中の経歴・恋愛・台詞・敵・数値・画像・音はゲーム用の創作で、実在のサービスの配信・課金・アカウント・ランキングとは連携しません。東京ドーム公演は物語の結末で、実際の開催を示しません。
