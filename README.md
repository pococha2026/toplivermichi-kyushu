# トップライバーへの道 九州編（公開版）

男女混合アイドルグループを脱退したヒロインと2人で旅立ち、九州・沖縄で仲間を集めてS6トップライバーへ導く、昭和風ドットのスマホ向けRPGです。

- 遊び方：`index.html` を開くだけ（スマホの縦画面向け）。GitHub Pages で公開しています。
- 収録範囲：九州・沖縄の全17拠点、本編M01～M17（大牟田市は九州編クリア後）
- 記録：遊んでいるブラウザ内に自動保存されます。閲覧データを消すと記録も消えるので、設定の「バックアップを表示」で控えを取ってください。

## ご注意

配信文化を参考にした**非公式の創作ゲーム**です。人物・台詞・敵・数値・画像・音はゲーム用の創作で、実在のサービスの配信・課金・アカウント・ランキングとは連携しません。

## 更新について

この公開版は、制作者が確認したうえで手動で更新します。開発中の版とは内容が異なる場合があります。版と更新日は `VERSION.txt` とタイトル画面に表示しています。

## v6.11 の追加・調整

- 全17街に配信文化を題材にした物語・会話・推し色の街飾りを追加。仲間に配信での役割を設定。
- 各街に「ファミリー交流所（絆）」「特別チャレンジ受付（挑）」を配置。メニューの「街イベント」「特別挑戦」からも利用できます。
- 街イベント17件：住民2人と会話、この更新後の地域通常戦闘2勝、現在の職業で熟練度3以上の仲間が条件。報酬は各街1回。
- 特別チャレンジ8件：本編クリアに応じて解放。コメント・キラコメ・職業技・熟練技・防御・制限ターンなどの達成課題があります。
- 特別挑戦は毎回ゴールドの参加料が必要です。限定装備8種・経験値・熟練度などの報酬は初回達成のみ。練習挑戦は報酬なし。全滅時の追加ゴールド損失はありません。
- 配信を題材にした道具6種を追加。既存の武器・防具の攻撃・防御補正を1.3倍（端数切り上げ）に強化。
- 通常敵・ボスのHP、防御、攻撃を強化。新しく始まるボス戦には通常攻撃軽減シールドと長期戦の攻撃上昇を追加し、職業技・応援連携・装備の価値を高めました。
- 総合レベル・熟練度の成長ペース、取得済みの名前・本編進行・所持品は継続します。新施設の配置に合わせ、位置が不適切な場合は安全地点に補正します。

戦闘のエール・連携・技・チャレンジ条件はゲーム独自の設定です。実サービスの応援ポイント計算式やイベント条件を再現するものではありません。
