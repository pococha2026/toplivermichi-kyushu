# トップライバーへの道 九州編・四国中国編（公開版）

男女混合アイドルグループを脱退したヒロインと2人で旅立ち、九州・沖縄で仲間を集めてS6トップライバーへ導く、昭和風ドットのスマホ向けRPGです。

- 遊び方：`index.html` を開くだけ（スマホの縦画面向け）。GitHub Pages で公開しています。
- 収録範囲：九州・沖縄17拠点＋四国・中国9拠点。本編M01～M17・C01～C09（大牟田編M17は任意）
- 記録：遊んでいるブラウザ内に自動保存されます。閲覧データを消すと記録も消えるので、設定の「バックアップを表示」で控えを取ってください。

## ご注意

配信文化を参考にした**非公式の創作ゲーム**です。人物・台詞・敵・数値・画像・音はゲーム用の創作で、実在のサービスの配信・課金・アカウント・ランキングとは連携しません。

## 更新について

この公開版は、制作者が確認したうえで手動で更新します。開発中の版とは内容が異なる場合があります。版と更新日は `VERSION.txt` とタイトル画面に表示しています。

## v6.17 特別エリアの未クリア案内

- 解放済みの未クリア項目を、探索画面の常時案内に件数・名前付きで表示。タップすると進行一覧を開けます。
- 大牟田市編はM17の配信目標達成、特設エリア10か所は各守護者撃破をクリアとして判定。特設チャレンジ10件の未達成は別に数えます。
- 未訪問・攻略中・ボス後の配信待ち・クリア済みを区別。地図・依頼帳・ファミリー施設・特設エリア一覧にも案内を追加しました。
- 一覧から進め方、入口、解放条件を確認できます。未解放・育成待ちとクリア済みは折りたたんで確認できます。
- 既存のセーブから進行状況を自動判定し、クリアした項目は未クリア案内から外れます。

## v6.16 四国・中国エリア編

- 九州本編M16クリア後、地図の「四国・中国エリア編の進行・出発」、またはファミリー交流所から松山市へ出発できます。M17のクリアは不要です。
- 松山→高知→徳島→高松→岡山→鳥取→松江→山口→広島の9都市。本編C01～C09、任意依頼CS01～CS09、街の交流祭9件、通常敵27エリア（各50種）、地域ボス9体を追加しました。
- 街ごとの合同配信の物語が進むと、次の都市が解放されます。配信目標がある本編は、ボス撃破後に依頼帳から配信を行います。
- レベル・同行者・装備・名前・ジョブ熟練度・習得技・九州の進行を引き継ぎます。九州クリア済みの既存セーブでも解放されます。
- 適正レベルは松山110～120から広島350～360へ上昇。新章にもボス手動操作、同行4人まで、同行者のみ経験値・熟練度獲得のルールが適用されます。
- 各街に全22職の専用装備（武器・防具・アクセサリー、合計594種）、地域共通装備27種、ボス初回限定の絆装備9種を追加。専用品は現在の職業と熟練度30～110の条件があります。
- 新しい街にもショップ・宿・控室・ファミリー施設・駅を配置。駅の移動は距離に応じたゴールドと旅程枠1が必要です。四国の連絡船などを含む路線・距離・運賃はゲーム内の架空設定です。

## v6.15 育成・同行者

- 同行は最大4人。街のファミリー施設で入れ替え、経験値・熟練度は同行者のみ獲得します。
- パーティレベル・ジョブ熟練度上限999。特設エリア10か所、通常敵500種、守護者10体、特設チャレンジ10件を追加。
- 転職時は前職の専用装備を外し、習得技・職業別熟練度・職業特有の永続ボーナスを引き継ぎます。

## v6.11 の追加・調整

- 全17街に配信文化を題材にした物語・会話・推し色の街飾りを追加。仲間に配信での役割を設定。
- 各街に「ファミリー交流所（絆）」「特別チャレンジ受付（挑）」を配置。メニューの「街イベント」「特別挑戦」からも利用できます。
- 街イベント17件：住民2人と会話、この更新後の地域通常戦闘2勝、現在の職業で熟練度3以上の仲間が条件。報酬は各街1回。
- 特別チャレンジ8件：本編クリアに応じて解放。コメント・キラコメ・職業技・熟練技・防御・制限ターンなどの達成課題があります。
- 特別挑戦は毎回ゴールドの参加料が必要です。限定装備8種・経験値・熟練度などの報酬は初回達成のみ。練習挑戦は報酬なし。全滅時の追加ゴールド損失はありません。
- 配信を題材にした道具6種を追加。既存の武器・防具の攻撃・防御補正を1.3倍（端数切り上げ）に強化。
- 通常敵・ボスのHP、防御、攻撃を強化。新しく始まるボス戦には通常攻撃軽減シールドと長期戦の攻撃上昇を追加し、職業技・応援連携・装備の価値を高めました。
- 総合レベル・熟練度の成長ペース、取得済みの名前・本編進行・所持品は継続します。新施設の配置に合わせ、位置が不適切な場合は安全地点に補正します。

戦闘のエール・連携・技・チャレンジ条件はゲーム独自の設定です。実サービスの応援ポイント計算式やイベント条件を再現するものではありません。
