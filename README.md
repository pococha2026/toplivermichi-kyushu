# トップライバーへの道 九州編・四国中国編（公開版）

男女混合アイドルグループを脱退したヒロインと2人で旅立ち、九州・沖縄で仲間を集めてS6トップライバーへ導く、昭和風ドットのスマホ向けRPGです。

- 遊び方：`index.html` を開くだけ（スマホの縦画面向け）。GitHub Pages で公開しています。
- 収録範囲：九州・沖縄17拠点＋四国・中国9拠点。本編M01～M17・C01～C09（大牟田編M17は任意）
- 記録：遊んでいるブラウザ内に自動保存されます。閲覧データを消すと記録も消えるので、設定の「バックアップを表示」で控えを取ってください。

## ご注意

配信文化を参考にした**非公式の創作ゲーム**です。人物・台詞・敵・数値・画像・音はゲーム用の創作で、実在のサービスの配信・課金・アカウント・ランキングとは連携しません。
